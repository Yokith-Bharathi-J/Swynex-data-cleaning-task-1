# Task 1: Data Cleaning & Preparation

**Internship task:** Data Analyst Internship — Swynex  
**Project:** Supermarket Sales Data Cleaning  
**Tools:** Python, pandas, Jupyter Notebook / Google Colab

## Objective
Prepare a public supermarket sales dataset for analysis by inspecting missing values, duplicate records, data types, inconsistent category labels, and invalid values.

## Dataset
- Original public dataset: [Supermarket Sales on Kaggle](https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales)
- Direct CSV mirror used by the notebook: [supermarket_sales.csv](https://raw.githubusercontent.com/deepakorani/Supermarket-Sales-Kaggle-Dataset/main/supermarket_sales.csv)
- The dataset describes transactions from three supermarket branches and includes product, customer, payment, date/time, and sales fields.

The notebook downloads the public CSV when run. Keep the source file unchanged in `data/raw_supermarket_sales.csv` and write the cleaned version to `data/cleaned_supermarket_sales.csv`.

## What the project checks and cleans
1. **Missing values:** reports null counts by column. It does not invent replacement values; unresolved missing values are retained and documented.
2. **Duplicate records:** reports exact duplicate rows and removes exact duplicates.
3. **Column names:** trims whitespace and standardizes column names to lowercase snake_case.
4. **Data types:** converts numeric fields to numeric types, `date` to datetime, and `time` to a consistent string representation. Unparseable values become missing and are counted in the audit.
5. **Inconsistent text values:** trims extra spaces and normalizes capitalization for known categorical fields while preserving the underlying meaning.
6. **Validation:** checks expected category values, non-positive unit prices/quantities, rating range, and sales arithmetic where relevant. It flags suspicious values rather than silently changing them.
7. **Outputs:** saves the cleaned CSV and a JSON cleaning report with before/after counts and issue summaries.

## Results
The exact counts are generated by the script at runtime and written to `data/cleaning_report.json`. Do not claim that missing values or duplicates were found unless the report confirms them. A clean dataset can legitimately have zero missing values or duplicates; reporting that accurately is part of data quality work.
